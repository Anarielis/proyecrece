
  # Sitio web de recetas

  This is a code bundle for Sitio web de recetas. The original project is available at https://www.figma.com/design/oL7Pvx4UO1QvkFkTkAaAZh/Sitio-web-de-recetas.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Deployment to GitHub Pages

  To deploy this project to GitHub Pages:

  1. Make sure you have committed all your changes to git
  2. Run `npm run deploy` to build and deploy to GitHub Pages
  3. The site will be available at https://Anarielis.github.io/proyecrece/

  Make sure your GitHub repository settings have GitHub Pages enabled and set to deploy from the `gh-pages` branch.
